## 🏗 What I've Built

### OAZIS — Enterprise GRC Platform
*Risk management, internal audit & compliance. Listed in the Russian Software Registry. Deployed at major Russian enterprises and banks.*

- Designed and built the backend from scratch: **16 microservices** on Java 17 + Kotlin + Spring Boot 3
- Deployed to **Kubernetes** via Helm, full GitLab CI/CD pipeline
- Solved authentication at scale: **Spring Cloud Gateway** with XTraceId pattern + Redis TTL — eliminated systemic 401 errors in long-running processes
- Optimized hierarchical access control: **PostgreSQL ltree** queries (evaluated Neo4j as alternative, chose native solution)
- Introduced **TestContainers** integration tests across all 16 services — real PostgreSQL + Redis containers instead of mocks
- Developed a **Kotlin runtime executor** — allows clients to inject custom business logic scripts without core changes
- Built event-driven architecture with **Apache Kafka** — custom headers for distributed tracing
- Initiated and delivered **Cucumber E2E** test suite — presented ROI to business stakeholders
- Load tested under production profile: **55 parallel threads** (ВТБ), identified and resolved bottlenecks
